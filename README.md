# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-26
## REG NO: 26017329
## NAME : M RAMYA

## AIM: 
To design the given 3D solid model of a Four-Legged Table/Frame Structure and convert it into 2D orthographic views per ISO standards using Autodesk Fusion 360.

## REQUIREMENTS: 
• Software. Autodesk Fusion 360 (3D CAD/CAM modeling suite) with an active user account.

• Operating System. Microsoft Windows 10 (64-bit) operating system.

• Memory & Graphics. 16 GB RAM paired with integrated or dedicated graphics supporting 1 GB or more VRAM.

• Internet Connectivity. A stable broadband connection with at least 2.5 Mbps download and 500 Kbps upload speeds for cloud synchronization.

• Peripherals. A standard keyboard, a three-button scroll mouse, and a display monitor.


## PROCEDURE:

## STEP-1:

Launch Autodesk Fusion 360, navigate to the File menu, and select New Design to open a new workspace.

## STEP-2:

Select the Create Sketch option from the toolbar and choose the Top (XY) Plane as the primary sketching plane.

## STEP-3:

1. Create the square tabletop profile using Rectangle and Sketch Dimension tools, then click Finish Sketch.
2. Create a secondary sketch on the tabletop face to draw the four square corner leg profiles using Rectangle and Equal constraints, then click Finish Sketch.

## STEP-4:

Use the Extrude option (shortcut E) to extrude the square tabletop slab and the four corner legs to their respective heights to convert the 2D profiles into a 3D solid model.

## STEP-5:

Save the completed 3D model and switch the workspace dropdown from Design to Drawing (From Design) per ISO standards.

## STEP-6:

1. Select the Base View tool and position the primary view of the model on the drawing sheet.
2. Select the Projected View tool to generate the corresponding top, side, and isometric orthographic projections, apply dimensions, and save the drawing sheet.
